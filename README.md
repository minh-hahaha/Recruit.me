# Recruit.me (Team Maryland)

Link:
http://recruit-me3.s3-website-us-east-1.amazonaws.com/

Use Cases implemented for Iteration 3:

Admin:
  - Report companies
  - Report jobs for company
  - report applicants

Company:
  - Review Applicants for Job
  - A company can report on the number of applicants that match a given list of skills, S1, S2, ...

Applicant:
  - accept offer
    
Use Cases implemented for Iteration 2:

Company:
  - Activate Job
  - Close Job
  - Review Applicants for job (not graded in iteration 2)
  - Offer Jobs
  - rescind offer to applicant

Applicant:
  - Search Jobs [page]
  - Apply to job
  - accept offer (not graded in iteration 2)
  - withdraw from job
  - reject offer from company

Use Cases implemented for Iteration 1:

Company:
  - Register Company
  - Review Company Profile
  - Edit Company Profile
  - Create Job
  - Edit Job

Applicant:
  - Register Applicant
  - Review Profile
  - Edit Profile
